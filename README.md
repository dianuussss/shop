# Cozy Shop

## Что реализовано

- каталог товаров с карточками, ценой и кнопкой добавления в корзину;
- корзина с изменением количества товаров и удалением позиций;
- автоматический пересчет итоговой суммы;
- сохранение корзины в `localStorage`;
- форма оформления заказа;
- адаптивная верстка для ноутбуков, планшетов и телефонов.

## Запуск

Открыть `index.html` в браузере или запустить локальный сервер:

```bash
python3 -m http.server 8080
```

После этого перейти по адресу `http://localhost:8080`.
